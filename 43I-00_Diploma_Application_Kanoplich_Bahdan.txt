Прошу утвердить следующую тему в качестве дипломного проекта: 
Тема на английском языке: Web service for the automatic extraction and verification of facts from scientific publications based on NLI models. 
Тема на русском языке: Веб-сервис автоматического извлечения и верификации фактов из научных публикаций на основе NLI-моделей 
Описание проекта: 
English: 
The system analyzes a set of documents, extracts assertions, 
links them to supporting or contradictory excerpts, and 
generates a visual map of evidence and sources. 
Русский: 
Система анализирует набор документов, выделяет утверждения, 
связывает их с подтверждающими или противоречащими фрагментами и формирует визуальную карту доказательств и источников.

Критерии сложности и составные компоненты проекта:
№ 
	Критерий 
	Описание
	1 
	Back-end & 
Front-end
	Разработка клиент-серверной архитектуры. Back-end (например, Python/FastAPI) отвечает за пайплайн обработки документов, маршрутизацию данных и интеграцию с нейросетями. Front-end (React/Vue.js) реализует интерактивный интерфейс для загрузки текстов и динамической визуализации графа связей.
	2 
	Adaptive UI 
(Web/Mobile)
	Создание адаптивного пользовательского интерфейса, обеспечивающего корректное отображение, 
масштабирование и удобную навигацию по визуальной карте доказательств на десктопных и мобильных устройствах.
	3 
	Database & ML 
model
	Проектирование хранилища данных (реляционная БД для метаданных + графовая БД, например, Neo4j, для хранения узлов и связей). Интеграция ML/NLP моделей (LLM, Sentence Transformers) для 
автоматического извлечения утверждений (claims), семантического поиска и классификации 
(подтверждение/опровержение).
	4 
	Cloud 
	Контейнеризация приложения (Docker) и 
развертывание в облачной инфраструктуре (например, AWS, GCP). Настройка пайплайна непрерывной интеграции и доставки (CI/CD) для обеспечения масштабируемости системы.
	5 
	API 
documentation
	Разработка спецификации и документирование программного интерфейса (REST API / GraphQL с использованием Swagger/OpenAPI) для стандартизации клиент-серверного взаимодействия и возможности интеграции системы со сторонними сервисами.
